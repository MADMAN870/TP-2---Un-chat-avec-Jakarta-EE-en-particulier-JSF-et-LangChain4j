# TP 2 — Un chat avec Jakarta EE, JSF et LangChain4j

Projet réalisé dans le cadre des travaux pratiques EMSI.

## Technologies

- Java
- Jakarta EE
- Jakarta Faces (JSF)
- LangChain4j
- Maven
- Google Gemini

## Structure du projet

- `src/main/java/ma/emsi/` : classes Java et exemples LangChain4j.
- `infos.txt` : document utilisé pour les tests de chargement de documents.
- `ai.md` : déclaration d’utilisation de l’intelligence artificielle.

## Compilation

```bash
mvn clean compile
```
